# Ghost admin app (Windows) — what it does and what it does not protect

## What it is
`GhostAdmin.exe` runs on the PC that hosts the relay. It starts the relay (`ghost-relay.exe`) and Cloudflare's quick tunnel,
shows the public address, creates single-use invitation codes and lists registered users. Everything is a button; there are no console commands.

## Design
- **Password gate.** First run creates an admin password (≥10 characters, no recovery). It is asked to open the app AND again before every action
  (start, stop, new invite, show users). Wrong guesses are slowed down (1, 2, 4 … 60 seconds).
- **Encrypted at rest.** The only file the app keeps is `%LOCALAPPDATA%\GhostAdmin\vault.bin`: AES-256-GCM (.NET platform crypto) under a key from
  PBKDF2-HMAC-SHA256 (600,000 rounds, random salt, fresh nonce per save, header authenticated). It holds the relay's admin token, settings and the relay's
  account snapshot (usernames, public keys, invite hashes). The relay itself is started WITHOUT a data file, so it writes nothing to disk.
- **Admin actions never go through the tunnel.** The relay has a second, loopback-only port for admin requests; the tunnel forwards only the public port.
  The admin token is generated by the app, kept in the vault, and never shown.
- **Screenshots.** Every window calls `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` (Windows 10 2004+; older versions get a black window).
- **Clipboard.** Copies are marked "do not keep in history / do not sync" and cleared after 60 seconds if unchanged.
- **Children die with the app.** The relay and tunnel run inside a Windows job object, so if the app is killed they end too.

## Registered users and their addresses (privacy change)
The user list shows each username and the last address it connected from. This is a deliberate, opt-in capability of the relay (`-record-ip`, which the app turns on):
addresses are kept **in the relay's memory only**, never written to disk or logs, and are forgotten when the relay stops. Through the tunnel the address is the one
Cloudflare reports (`Cf-Connecting-Ip`), trusted only when the connection comes from this PC's own `cloudflared`. **Tell your users** that the relay operator can see
the address they connect from; that is a real privacy cost, and it was not the default before.

## Limits (be honest with yourself)
- Someone who is logged in to your Windows account while the app is unlocked can use it. Lock Windows when you leave.
- Capture exclusion stops Windows screenshots/recordings/screen-sharing, not a camera pointed at the monitor, malware that reads memory, or a hardware capture device on some setups.
- The admin password in memory and the decrypted vault in memory are not protected against malware running as you.
- Windows SmartScreen will warn that the program is from an unknown publisher (it is unsigned). The SHA-256 list in the download lets you check the files match this repository's CI build.
- The quick tunnel has no uptime guarantee and a new address every start; a fixed address needs your own domain and a named tunnel.
- The relay keeps messages in memory only. Stopping it drops undelivered messages (accounts and unused invites are restored from the encrypted vault).
- Not audited. UI layout has not been seen by me on a real screen.
